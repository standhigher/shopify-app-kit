## 快速开始

在宿主应用中安装并提供 React、Polaris 和 Polaris 样式：

```bash
npm install @standhigher/shopify-app-kit @shopify/polaris react react-dom
```

```tsx
import { AppProvider, Frame } from "@shopify/polaris";
import "@shopify/polaris/build/esm/styles.css";
import { ShopifyAppKitProvider } from "@standhigher/shopify-app-kit/core";
import { ToastProvider } from "@standhigher/shopify-app-kit/feedback";

export function App() {
  return (
    <AppProvider i18n={{}}>
      <Frame>
        <ShopifyAppKitProvider appName="Fulfillment Desk">
          <ToastProvider>
            <Routes />
          </ToastProvider>
        </ShopifyAppKitProvider>
      </Frame>
    </AppProvider>
  );
}
```

宿主负责 `@shopify/polaris`、`AppProvider`、`Frame` 和 CSS；App Kit 不会重复创建 Polaris context，也不会把 Polaris 打包进发布包。

## 如何阅读 Story

- **Canvas**：查看组件的实际渲染结果并执行按钮操作。
- **Controls**：Provider 等支持 args 的 Story 可以直接调整参数。
- **Docs**：查看参数表、宿主前置条件、fallback 和最小接入示例。
- 所有示例都可在没有 Shopify host 或 App Bridge 的环境中打开；需要宿主能力的功能会展示稳定的 fallback。

## Shopify host 与 fallback

- 在 Embedded App 中，App Bridge adapter 会优先使用宿主提供的能力。
- 没有 App Bridge 时，Navigation 使用浏览器导航，Resource Picker 返回 `canceled: true`，Save Bar 默认不渲染；需要自定义或本地 fallback 时通过 `renderers.saveBar` 提供。
- 外部 URL 仅允许安全协议；Admin 目标必须是相对 Shopify Admin 路径。
- 这些 fallback 便于本地开发和测试，但生产 Embedded App 仍应配置真实宿主能力。
